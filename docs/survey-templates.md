# 設問テンプレート

Survey詳細「設問テンプレートを保存」でJSONを書き出す。新規作成「JSONを読み込む」で読み込み、JSONを編集して「内容を確認」後に新しいSurveyとして保存する。読み込み・保存は配信を行わず、既存Surveyを更新しない。

現行Surveyスキーマに合わせた許可リストでname/title、通知文面、questions（選択肢・分岐条件を含む）だけを引き継ぐ。DB内部ID、Surveyの旧id、回答、利用者、配信日時は除外する。設問のid/indexは設問定義として保持する。回答結果のJSONとは異なる形式。旧形式のSurvey設定JSONも同じ許可リストで読み込める。

最大2MB。JSON構文、必須の名前・設問・type、重複index、選択肢形式、分岐参照を検証する。未知フィールドは除外する。確認画面は端末上での見え方の再現ではなく、保存内容の概要表示。失敗時は編集内容を保持する。

検証：node test/template.test.js、node test/paging.test.js、production build。

次期大規模改修：研究者がJSONを直接記述せず、Web上の設問編集フォームや別形式から作成できるエディターを検討する。設問種別、並べ替え、分岐、プレビュー、ファイル形式の版管理、既存テンプレート互換性を設計する。今回の範囲には含めない。
