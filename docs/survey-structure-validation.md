# Survey構造チェック（2026-10-06）

新規作成のJSON読み込み・内容確認・保存時に、構文と設問構造を検査する。
既存Surveyの「アンケートの構造をチェック」は読み取りのみ。既存データを自動修正しない。

- headerは先頭に1つ、footerは末尾に1つ、回答設問は最低1つ。
- 配列の並びとindexが0からの連番で一致すること。
- 現行アプリの9種類のtypeのみ。single/multiは空でない文字列の選択肢が必要。
- skipは存在する後方の設問へ。includeIfは手前の対応する選択式設問を参照。
- header/footerに分岐条件を設定しない。

エラーは位置と修正内容を日本語表示し、保存リクエスト前に停止する。
番号変更や欠落ページ補完は分岐の意味を変え得るため、自動修正しない。
テンプレート書き出しは既存のデータ抽出を維持し、不備があるデータも修正用に取り出せる。
この検査は分岐の研究上の意図や画面収まりを保証しない。実機確認は必要。
今回の対象は管理画面。APIへの直接送信・DB直接登録に対する強制検査は未実装。

検証: node test/template.test.js、npm run build。
